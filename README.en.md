# Bil4You – Internship Project

Bil4You is a responsive car dealership website built with **Next.js** as part of an internship project.  
The goal of the project was to design and implement a modern, user-friendly, and responsive website based on a Figma design and a structured development plan.

---

## 📌 Project Overview

The website includes the following pages:

- **Home**
- **Buy Cars** (list view + filter/sorting UI)
- **Sell Car** (form with validation + confirmation view)
- **Contact Us** (contact form + information + opening hours)
- **Car Detail Page** with interactive image gallery

The project follows the structure and requirements defined in the internship plan and was developed step-by-step from design to final implementation.

---

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- SCSS Modules
- Next/Image (image optimization)
- Responsive design (mobile-first)
- Semantic HTML

---

## 🎯 Features

- Fully responsive layout (Desktop / Tablet / Mobile 320px+)
- Interactive image gallery with clickable thumbnails
- Scrollable thumbnail row on mobile
- Frontend form validation
- Clear error messages

- Basic SEO implementation
- Production-ready build

## 🧭 Development Process

The project was completed in the following stages:

1. **Figma – Wireframes & UI Design**
   - Structure, navigation, and user flow
   - Color system, typography, and components
   - Clickable prototype

2. **Next.js – Project Setup**
   - Base layout (Header + Footer)
   - Routing for all pages
   - SCSS structure and UI kit setup

3. **Implementation**
   - Reusable components (Card, Button, FormField, etc.)
   - Responsive layout
   - Frontend form validation

4. **Polish & Quality Assurance**
   - Spacing and typography adjustments
   - Hover states
   - Accessibility improvements
   - Lighthouse testing
   - Documentation
