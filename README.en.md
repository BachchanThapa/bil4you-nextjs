# Bil4You – Internship Project

Bil4You is a responsive car dealership website built with Next.js as part of an internship project.  
The goal was to design and implement a modern UI based on a Figma prototype and deliver a fully responsive frontend application.

---

## 📌 Project Overview

The website includes the following pages:

- Homepage
- Köp bilar (Car listing with filter/sort UI)
- Sälja bil (Form with validation + confirmation)
- Kontakt oss (Contact form + business info + opening hours)
- Car detail page with interactive image gallery

The project follows the internship structure described in the project plan (see internship documentation).

---

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- SCSS Modules
- Next/Image optimization
- Responsive design (mobile-first approach)

---

## 🎯 Features

- Fully responsive layout (Desktop / Tablet / Mobile 320px+)
- Interactive car gallery with thumbnail navigation
- Scrollable mobile thumbnails
- Form validation (frontend)
- Accessible buttons and semantic HTML
- SEO basics (metadata, semantic headings)
- Production build ready

---

## ♿ Accessibility

- Semantic HTML structure
- Proper `alt` attributes on images
- `aria-label` usage where required
- Keyboard-accessible buttons
- Clear focus states

---

## 🔎 SEO Basics

- Metadata configuration via Next.js `metadata`
- Static route generation
- Semantic heading structure
- Optimized images using `next/image`
