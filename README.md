# 🚗 Bil4You

**Full-stack car marketplace developed during my LIA (internship) as part of my Frontend Developer education.**

Bil4You started during **LIA 1** as a responsive frontend project based on Figma designs. During **LIA 2**, I continued developing the same project into a dynamic full-stack application with authentication, database integration, image storage, user features, an admin system and an AI assistant.

---

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **SCSS Modules**
- **Supabase**
- **PostgreSQL**
- **Supabase Auth**
- **Supabase Storage**
- **Vercel**
- **Ollama / Local AI integration**

---

## ✨ Main Features

### 🚘 Car Marketplace

- Browse approved car listings
- Search, filter and sort cars
- Dynamic car detail pages
- Responsive design

### 👤 User Features

- Register and log in
- Password reset
- Create car advertisements
- Upload multiple car images
- Manage own advertisements
- Mark cars as sold
- Save favorite cars
- Send interest inquiries

### 🛡️ Admin

- Role-based admin access
- Review and approve advertisements
- Dashboard with dynamic statistics
- Manage contact messages

### 🤖 AI Assistant

- Integrated AI assistant
- Local AI development using Ollama
- Car-related assistance directly from the application

---

## 📈 Project Development

### LIA 1 — Frontend

The first version focused on building the user interface and responsive design using:

`Next.js` · `TypeScript` · `SCSS` · `Figma`

This version was deployed to Vercel as a static frontend application.

### LIA 2 — Full Stack

The project was later expanded with:

`Supabase` · `PostgreSQL` · `Authentication` · `Storage` · `CRUD` · `Admin functionality` · `AI integration`

This transformed Bil4You from a frontend prototype into a functional full-stack application.
