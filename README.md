# Bil4You – Praktikprojekt

Bil4You är en responsiv bilförsäljningswebbplats byggd med Next.js som en del av ett praktikprojekt.  
Målet var att designa och implementera en modern och användarvänlig webbplats baserad på en Figma-design.

---

## 📌 Projektöversikt

Webbplatsen innehåller följande sidor:

- Startsida
- Köp bilar (lista + filter/sortering UI)
- Sälj bil (formulär med validering + bekräftelse)
- Kontakt oss (kontaktformulär + information + öppettider)
- Bilens detaljsida med interaktiv bildgalleri

Projektet följer den struktur och plan som angavs i praktikplanen.

---

## 🛠 Teknikstack

- Next.js (App Router)
- TypeScript
- SCSS Modules
- Next/Image (bildoptimering)
- Responsiv design (mobile-first)

---

## 🎯 Funktioner

- Fullt responsiv layout (Desktop / Tablet / Mobil 320px+)
- Interaktiv bildgalleri med klickbara thumbnails
- Scrollbar thumbnail-rad på mobil
- Formulärvalidering (frontend)
- Tillgängliga knappar och semantisk HTML
- Grundläggande SEO
- Produktionsredo build

---

## ♿ Tillgänglighet (Accessibility)

- Semantisk HTML-struktur
- Korrekt användning av `alt`-attribut
- `aria-label` där det behövs
- Tangentbordsnavigering
- Tydliga fokusmarkeringar

---

## 🔎 SEO-grunder

- Metadata via Next.js `metadata`
- Statisk sidgenerering
- Semantisk rubrikstruktur
- Optimerade bilder via `next/image`
